# Enterprise SIEM Security Threat Monitoring Station

A professional-grade Security Information and Event Management (SIEM) dashboard designed to parse telemetry logs and deploy Machine Learning for anomaly detection.

## 🚀 Execution Framework

### 1. Provision Environment
Install the complete enterprise telemetry tracking dependencies using pip:
```bash
python -m pip install streamlit pandas plotly scikit-learn
```

### 2. Launch SIEM Station
Initialize the structural monitoring engine and dashboard interface via python network sockets:
```bash
python -m streamlit run app.py
```
